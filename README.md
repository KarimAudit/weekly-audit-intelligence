# Audit Intelligence Agent (AIA)

An autonomous AI-powered research assistant that monitors trusted sources in:

- Internal Audit
- Internal Controls
- Governance
- Enterprise Risk Management
- Public Sector Reform
- Artificial Intelligence for Audit

Every week the agent:

1. Collects updates from trusted sources.
2. Removes duplicates.
3. Produces an executive-level intelligence brief.
4. Stores reports in GitHub.
5. Emails the report automatically.

## Tech Stack

- GitHub Actions
- Gemini API
- GitHub Repository
- Gmail
- Markdown Reports
